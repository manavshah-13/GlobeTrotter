# Security Policy

## Supported Versions

We actively support and provide security fixes for the latest version of GlobeTrotter running on main:

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

---

## Reporting a Vulnerability

The GlobeTrotter maintainers take security and data privacy seriously. If you discover a vulnerability, please **do not** open a public GitHub issue.

Instead, please report security concerns responsibly via one of the following methods:

1. **GitHub Private Security Advisory**: Submit a private advisory at https://github.com/manavshah-13/GlobeTrotter/security/advisories/new.
2. **Email**: Contact the maintainers directly at maintainers@globetrotter.io (or reach out to the project leads via their GitHub profile).

### What to Include in Your Report
To help us triage and resolve the issue quickly, please include:
- A clear description of the vulnerability and its potential impact
- Detailed step-by-step instructions or proof-of-concept (PoC) script to reproduce the issue
- Affected endpoint, component, or file
- Any recommended mitigations or workarounds

---

## Response Timeline

- **Initial Response**: Within 48 hours of report receipt.
- **Triage & Status Update**: Within 5 business days.
- **Fix & Public Disclosure**: Coordinated disclosure after a fix is verified and deployed.

We appreciate your effort in keeping GlobeTrotter and its community safe.
